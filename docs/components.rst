Components
==========

This section describes the main UI components used in Supervisor Finder.

Overview
--------

The application is done around a set of React components that provide the main user experience for students and supervisors.

All Components Simplified
-------------------------

- Signin: allows users to sign in to the application.
- Signup: allows new users to create an account.
- Supervisors: displays supervisor profiles and search results.
- Profile: shows the supervisor profile details and editable information.
- Add_Project_Idea: allows supervisors to add project ideas.
- Project_ideas: displays project ideas submitted by supervisors.
- NavBar: provides navigation across the application.

How They Work Together
-----------------------

These components work together to support the core workflows of the app:

- Students browse supervisors and project ideas.
- Supervisors update their profile and manage project ideas.
- Navigation helps users move between relevant pages.
