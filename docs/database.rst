Database
========

Overview
********

The Web application uses Supabase as its backend database. Supabase provides a PostgreSQL database with built-in authentication and real-time capabilities. The database is organised around supervisors profiles, project ideas, and tags of interest.

Schema
******

Supabase uses a relational database schema to store data. The main tables include:

.. code-block:: sql

   create table public.profile (
     name text null,
     contact_email text null,
     contact_office text null,
     email text null,
     id uuid not null,
     constraint profile_pkey primary key (id),
     constraint Profile_email_key unique (email),
     constraint profile_id_fkey foreign key (id) references auth.users (id)
   ) tablespace pg_default;

   create table public.profile_project (
     profile_id uuid not null,
     project_id bigint generated by default as identity not null,
     title text not null,
     description text not null,
     constraint profile_project_pkey primary key (profile_id, project_id),
     constraint profile_project_profile_id_fkey foreign key (profile_id) references profile (id)
   ) tablespace pg_default;

   create table public.profile_tag (
     profile_id uuid not null,
     tag_id bigint not null,
     constraint profile_tag_pkey primary key (profile_id, tag_id),
     constraint profile_tag_profile_id_fkey foreign key (profile_id) references profile (id),
     constraint profile_tag_tag_id_fkey foreign key (tag_id) references tag (id)
   ) tablespace pg_default;

   create table public.tag (
     id bigint generated by default as identity not null,
     tag_name text null,
     constraint Tags_pkey primary key (id)
   ) tablespace pg_default;

Tables
******

Profile Table
-------------

- **id:** Unique identifier for the supervisor profile (UUID) [PK].
- **name:** Name of the supervisor (text).
- **contact_email:** Contact email of the supervisor for students to use (text).
- **contact_office:** Contact office of the supervisor (text).
- **email:** Email of the supervisor (text).

Profile_project Table
---------------------

- **profile_id:** Foreign key referencing the supervisor profile (UUID) [PK].
- **project_id:** Unique identifier for the project idea (bigint) [PK].
- **title:** Title of the project idea (text).
- **description:** Description of the project idea (text).

Profile_tag Table
-----------------

- **profile_id:** Foreign key referencing the supervisor profile (UUID) [PK].
- **tag_id:** Foreign key referencing the tag (bigint) [PK].

Tag Table
---------

- **id:** Unique identifier for the tag (bigint) [PK].
- **tag_name:** Name of the tag (text).


Policies
********

Policies are set up in Supabase to control access to the database tables. The policies ensure that only authenticated users can read and write data, and that users can only modify their own profiles and project ideas. They are also Policies in place to allow students to view supervisor profiles and project ideas without being able to modify them.
