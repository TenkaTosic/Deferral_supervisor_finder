Installation
============

This section explains how to set up the Supervisor Finder project locally.

Prerequisites
-------------

Make sure you have the following installed on your machine:

- Node.js and npm
- A modern web browser
- A Supabase account for database access

Setup Steps
-----------

1. Clone the repository:

   .. code-block:: bash

      git clone https://github.com/TenkaTosic/Deferral_supervisor_finder.git
      cd Deferral_supervisor_finder

2. Install dependencies:

   .. code-block:: bash

      npm install

3. Start the development server:

   .. code-block:: bash

      npm run dev

4. Open the local URL shown by Vite in your browser.

Environment Variables
---------------------

If the application uses Supabase authentication or database access, make sure your environment variables are configured correctly in your project settings.
