Contribution Guidelines
======================

Thank you for contributing to Supervisor Finder.

How to Contribute
-----------------

1. Fork the repository and create a new branch.
2. Make your changes and test them locally.
3. Keep your code clean and easy to understand.
4. Submit a pull request with a clear description of your change.

Recommended Practices
---------------------

- Follow the existing project structure and code style.
- Write clear commit messages.
- Document new features or changes where appropriate.
- Test the app before submitting changes.

Questions or Issues
-------------------

If you encounter a bug or have a feature suggestion, open an issue in the repository so it can be discussed.
